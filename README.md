# Screen & Sound Recorder website

The landing page for [Screen & Sound Recorder](https://chromewebstore.google.com/detail/gemaaokegkngogofohbmpjndjohbkkob), a Chrome extension for Mac that records the screen with computer sound and the microphone, even with headphones on.

Published with GitHub Pages at https://yz-01.github.io/screen-and-sound-recorder/.

| Path | Purpose |
| --- | --- |
| `index.html` | The page, with structured data for search engines (SoftwareApplication and FAQ) |
| `style.css` | Page styles, light and dark |
| `assets/` | Icon, social preview image, demo video and captions, screenshots |
| `robots.txt`, `sitemap.xml` | Help search engines find the page |
